# 1. Sơ đồ chuỗi Prompt

Prompt 1: Phân tích khách hàng  
-> Prompt 2: Xây dựng thông điệp  
-> Prompt 3: Lập kế hoạch 7 ngày  
-> Prompt 4: Viết nội dung quảng cáo  
-> Prompt 5: Kiểm tra tính thống nhất.

# 2. Chân dung khách hàng

- Đối tượng: Sinh viên năm nhất, 18–20 tuổi.
- Nhu cầu: Muốn học lập trình từ cơ bản.
- Khó khăn: Chưa có kiến thức và kinh nghiệm lập trình.

# 3. Thông điệp chính

"Bắt đầu học lập trình Python dễ dàng chỉ với 8 tuần!"

# 4. Lịch đăng nội dung 7 ngày

| Ngày | Nội dung |
|---|---|
| 1 | Giới thiệu khóa học |
| 2 | Lợi ích của Python |
| 3 | Khó khăn khi mới học |
| 4 | Nội dung khóa học |
| 5 | Bài quảng cáo Facebook |
| 6 | Video TikTok giới thiệu |
| 7 | Kêu gọi đăng ký tư vấn |

# 5. Nội dung quảng cáo

**Facebook 1:** Bạn muốn học lập trình nhưng chưa biết bắt đầu từ đâu? Hãy tham gia khóa Python cơ bản trong 8 tuần dành cho người mới bắt đầu. Đăng ký tư vấn ngay!

**Facebook 2:** Sinh viên năm nhất muốn tìm hiểu công nghệ? Hãy bắt đầu với khóa học Python cơ bản kéo dài 8 tuần. Đăng ký tư vấn ngay hôm nay!

**TikTok 1 (30–45 giây):**
- Mở đầu: Bạn muốn học lập trình?
- Nội dung: Giới thiệu khóa Python cơ bản trong 8 tuần.
- Kết thúc: Đăng ký tư vấn ngay!

**TikTok 2 (30–45 giây):**
- Mở đầu: Sinh viên năm nhất có nên học Python?
- Nội dung: Giới thiệu khóa học dành cho người mới.
- Kết thúc: Tham gia tư vấn ngay hôm nay!

# 6. Kiểm tra tính thống nhất

- Đúng đối tượng: Sinh viên 18–20 tuổi.
- Đúng thời lượng: 8 tuần.
- Nội dung thống nhất trên Facebook và TikTok.
- Mục tiêu: Thu hút 100 lượt đăng ký tư vấn.
